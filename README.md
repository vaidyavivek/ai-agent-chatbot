# AI Agent Chatbot 🤖

A conversational AI agent built with Python, LangChain, and LangGraph. 
Uses OpenAI's GPT model with custom tool-calling capabilities including a calculator tool.

## Tech Stack
- Python
- LangChain
- LangGraph
- OpenAI API
- uv

## How to Run
1. Clone the repo
2. Add your OpenAI API key to a `.env` file
3. Run `uv run src/project1/main.py`
